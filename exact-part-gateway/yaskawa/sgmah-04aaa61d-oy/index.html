What to verify before buying

Exact suffix / nameplate

Match SGMAH-04AAA61D-OY character for character on the actual motor nameplate. Do not accept a box label or a nearby SGMAH code as proof of compatibility.

Voltage conflict

Resolve voltage from the actual motor nameplate and the installed drive documentation. The existing eBay listing mixes 110V and 230V fields, and the independent MRO page also mixes voltage descriptions. These seller fields cannot establish compatibility.

Encoder, shaft and brake

Use the exact-model entry in the official Sigma-II catalogue to verify encoder type and resolution, shaft keyway and tapped end, brake option and connector arrangement. Obtain photographs of the actual unit and compare with the installed motor; a shared SGMAH base code does not establish a drop-in replacement.
