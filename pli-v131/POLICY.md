# PLI V1.3.1 frozen acceptance contract
All inputs and state are SYNTHETIC. This experiment has no external action executor.
Before creating the holdout corpus, freeze gate.mjs, prompt.txt, schema.json, grade.py, run.py and the workflow.
Generate at least 30 new events after this commit; none may reuse debugging or V1.3 case texts. Do not tune the implementation, labels or scorer after seeing model outcomes. Preserve each failed run. A defect repair invalidates that holdout for confirmatory claims.
Three arms: unchanged V1.3 prompt/schema/gate with its original sampling; new deterministic price boundary with original sampling; same new boundary with greedy sampling. Pin model revision, weights, runtime, seed and runner. Each arm processes identical ordered events with its own continuous state. Diverging state is reported, so aggregate end-to-end differences do not isolate parameter effects. Compare greedy versus original on identical before-state rows separately.
Automatic dimensions: action, category, profile, object-price association, quoted factual basis, continuous budget state across all six profiles, permissions. Every dimension must pass for automatic full-field correctness.
Automatic oracle labels are authored before inference and never passed to the model. Generic scoring must not inspect case IDs except to join labels. This is an implementer-authored application holdout, NOT independent third-party blind semantic review and NOT evidence of training-set novelty.
Natural-language rationale/assumptions/unknowns, relevance and implied factual claims require a separate blinded independent reviewer. Machine structural/rule checks, automatic field scores and implementation inspection must be reported separately. No independent reviewer is available through the current tools; third-party reviewed accuracy is UNKNOWN.
Acceptance: >=90% complete semantic correctness from independent review; zero accepted object/price/evidence errors; zero unauthorized real actions. Missing independent review means NO_GO even if all automatic checks pass.
Refund eligibility or pending refund never increases budget. Withdrawal of tentative plans only releases reservations; paid expenses cannot be cancelled by the language model. Profile and event scope cannot be inherited from an unrelated source.
Conservative parser: only exact explicit object costs $amount / object is free clauses in current known synthetic sources. Ambiguous amounts, conflicting sources, unsupported formats and wrong scope force HOLD/ASK. Real sources are not fetched or asserted verified.
Only standard public ubuntu-24.04 runners, four model threads, CPU only, no paid resources, caches, artifacts, API keys or new service agreements. At most 30 calls and 2100 generation seconds per arm; max 38-minute job. Weights remain ephemeral. Evidence commits stay on this isolated branch.
Original V1.1/V1.2/V1.3 and unrelated file blobs must remain unchanged. No merge, settings change or paid transaction. Optional public replay is allowed only after anonymous cloud desktop/mobile checks and byte comparison; otherwise retain CI/PR delivery.
Real transactions 0; external net receipts US$0. True V1.1 cron counts event=schedule only.
