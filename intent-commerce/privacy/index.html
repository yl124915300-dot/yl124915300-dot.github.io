Privacy

Updated 29 September 2026. This describes the current connector candidate. It has not been approved for public buyer use in Muse.

Data used to answer a request

If the connector becomes available, it will process the buyer's shopping request and any city, US ZIP code, search radius or coordinates the buyer provides. It uses these to interpret the request, filter offers and estimate straight-line distance. It does not ask for a buyer account, payment card, photo or Shopify store administration access.

Data sent to suppliers

Shopify Global Catalog receives search terms and, if supplied, a ZIP code for product and shipping context. A US ZIP may be sent to Zippopotam.us for an approximate ZIP centroid; the result can remain in process memory. Groupon receives state-scoped catalog requests and, only if a buyer chooses a Groupon offer for checkout, product and option identifiers for a cart. The raw buyer request is not sent to Groupon.

Data kept and deletion

The current connector code stores a random session ID, a small set of parsed preferences, selected offer snapshots, and checkout handoff events. Its session ledger does not store the raw buyer request, buyer ZIP code or buyer coordinates. Sessions become eligible for deletion after 24 hours and are purged at startup and hourly while the service runs. A local supplier index stores offer snapshots and a hash derived from Shopify search terms, budget and ZIP when supplied; the hash should not be treated as anonymous data. Groupon snapshots are excluded from search after six hours and Shopify snapshots after 30 minutes, then removed from disk during cleanup, normally within one further minute while the service runs. Public hosting and backup retention must be checked before launch.

For a deletion request, email yl124915300@gmail.com. Include a connector session ID if you have one; do not email payment details or passwords. Because sessions have no buyer account identity, a session ID helps locate the record. Sessions also expire automatically.

Checkout, commission and hosting

Buyers leave the connector for a supplier-controlled checkout. Intent Commerce does not receive card information or a verified order callback. Some eligible supplier links may earn a commission; commission does not affect ranking. Groupon commission attribution is not currently verified. This information site is hosted by GitHub Pages, which may process ordinary web request data under its own policies. A future public API host may also process network request data; its configuration must be reviewed before launch.
