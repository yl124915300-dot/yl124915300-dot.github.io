Privacy

Updated 29 September 2026. This describes the Connector implementation. Muse has not approved it for public buyer use.

Data used to answer a request

For a request sent to the Connector, it processes the buyer's shopping request and any city, US ZIP code, search radius or coordinates provided. It uses these to interpret the request, filter offers and estimate straight-line distance. It does not ask for a buyer account, payment card, photo or Shopify store administration access.

Data sent to suppliers

Shopify Global Catalog receives search terms and, if supplied, a ZIP code for product and shipping context. A US ZIP may be sent to Zippopotam.us for an approximate ZIP centroid; the supplied ZIP and centroid may be cached in D1 for up to 24 hours. Groupon receives state-scoped catalog requests. Product and option identifiers are sent for a cart only after a buyer confirms a Groupon result and the required partner binding check passes. The raw buyer request is not sent to Groupon.

Data kept and deletion

The Cloudflare Worker implementation stores random session IDs, selected offer snapshots and checkout handoff events in D1. Session records do not store the raw buyer request or buyer-provided coordinates. Sessions and handoff events expire after 24 hours. Shopify offer snapshots and query-context hashes derived from search terms, budget and a supplied ZIP expire after 30 minutes; the hash should not be treated as anonymous data. ZIP-centroid cache rows, including the supplied ZIP, expire after 24 hours. Groupon offer snapshots are excluded from search after six hours. City index metadata created by a request expires six hours after its last request; the default Los Angeles index identity remains as service configuration.

A scheduled task removes expired rows from the live D1 database roughly each minute while it runs. If that task is delayed or unavailable, physical deletion can also be delayed. Cloudflare's D1 Time Travel can retain recoverable historical database states for up to seven days on the Workers Free plan. Deleting a live row does not immediately erase every recoverable historical state.

For a deletion request, email yl124915300@gmail.com. Include a connector session ID if you have one; do not email payment details or passwords. Because sessions have no buyer account identity, a session ID helps locate the record. Sessions also expire automatically.

Checkout, commission and hosting

Buyers leave the Connector for a supplier-controlled checkout. Intent Commerce does not receive card information or a verified order callback. Some eligible supplier links may earn a commission; commission does not affect ranking. Groupon commission attribution is not currently verified. This information site is hosted by GitHub Pages. The Connector API is configured for Cloudflare Workers and D1; Cloudflare may process network request data when the API is used. The Worker code emits no custom log calls containing request bodies or credentials. Where Workers Logs is enabled, Cloudflare may retain invocation metadata for three days on the Workers Free plan.
