Connector documentation

Four-operation API contract · updated 29 September 2026

The Connector is a pre-review candidate at the fixed Cloudflare Worker hostname https://intent-commerce-muse.yl124915300.workers.dev/. Its four routes were checked over public HTTPS on 29 September 2026; GET /health and GET /openapi.json return JSON. Supplier coverage can still be warming. This page documents the contract; it does not establish Muse compatibility or approval.

How Muse would use it

  1. Receive an existing buyer shopping request.
  2. Call search_offers and then get_top3_results to show up to three ranked offers with limits.
  3. Call create_checkout_handoff only after the buyer chooses one shown result and asks to proceed. The supplier handles payment.

parse_intent is an optional preview step. No post-purchase, order or refund tool is exposed.

Operations

Groupon refuses a cart while its publisher binding is absent; Shopify passes through its supplied link. The Connector does not complete payment.

Access and limits

Tool calls require a server-to-server Bearer API key. The key is not a buyer credential and must not appear in prompts, browser code or this documentation. Search sessions use a signed token and expire after 24 hours. JSON requests are limited to 4,096 bytes. The Worker implementation limits authenticated calls to 30 and searches to three per minute. Muse authentication and end-to-end review remain separate checks.

The Worker implementation reads supplier snapshots from D1. Its configured scheduled refresh processes up to three Groupon catalog pages per invocation when it runs; the current sample can be incomplete, and Los Angeles is the default refresh location. A first request for another city or an unwarmed Shopify query may return a retryable 503 supplier_index_warming. GET /openapi.json serves the API contract from the Worker. A listed voucher does not verify a same-night booking or redemption slot. Checkout price, availability, fulfillment and payment remain with the supplier. Some eligible links may earn a commission; commission does not affect ranking. Groupon tracking is not currently verified.
